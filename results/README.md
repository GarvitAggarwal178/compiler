# Results — index

The project's conclusions, as opposed to its raw evidence (`experiments/`)
or its record of how it got there (`docs/project-log.md`).

| File | What it is |
|---|---|
| `findings.md` | The four findings that carry the project's actual result, each with numbers and an experiment-record citation. Start here after `docs/01-problem.md`. |
| `claims.md` | Every substantive claim made anywhere in this repository, one row each: the evidence behind it, an honest strength rating, and its caveats. Use this to check any specific number. |
| `superseded.md` | Every retracted or replaced number project-wide, what replaced it, and why. Presented as deliberate epistemic hygiene, not as a list of mistakes to be embarrassed about. |
| `presentation.html` | A static, self-contained presentation artifact built from committed measurement JSON and `dlc explain` output — no server, no build step. Regenerated by `harness/build_presentation.py`. |
