Counting contract: rule-derived tuple insertions include every checkpoint; loaded rows are excluded. Candidate-head attempts count repeated work. Naive bucket 0 and SCC-local delta buckets are not a global execution trace. Counts do not establish runtime or memory improvement.

I/O contract: exact LF-delimited serialized row sets, including empty files and empty-symbol rows. Plain TSV cannot encode embedded symbol tabs or LF unambiguously. Unrepresentable columns are shown as escaped bytes.
